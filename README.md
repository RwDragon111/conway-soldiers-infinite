# Солдаты Конвея — бесконечное поле

Браузерная версия [Conway’s Soldiers](https://abhikpal.gitlab.io/conway-soldiers/) на русском языке. Поле не имеет границ: начальная армия занимает всю нижнюю полуплоскость, включая клетки за пределами экрана. Она хранится не как огромный массив, а как правило заполнения и список изменённых клеток.

[Играть онлайн](https://rwdragon111.github.io/conway-soldiers-infinite/) · [Репозиторий на GitHub](https://github.com/RwDragon111/conway-soldiers-infinite)

## Запуск

Нужен Node.js 18 или новее. Установка зависимостей не требуется.

Из этой папки выполните:

```powershell
npm start
```

Или запустите PowerShell-скрипт:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Откройте [http://localhost:3000](http://localhost:3000). Сервер доступен только на этом компьютере. Для остановки нажмите `Ctrl+C` в терминале. Для другого порта перед запуском задайте `$env:PORT = '3001'`.

## GitHub Pages

Игра работает как статический сайт: сборка и сервер Node.js для публикации не нужны. Все пути к стилям и модулям относительные, поэтому сайт открывается и в подпапке репозитория.

GitHub Pages публикует сайт из ветки `main`, папки `/(root)`. После каждого push в `main` сайт обновляется автоматически. Файл `.nojekyll` отключает обработку сайта Jekyll.

## Как играть

- Нажмите на солдата, затем на подсвеченную клетку назначения. Прыжок идёт на две клетки по горизонтали или вертикали, через соседнего солдата, который удаляется. Клетка назначения должна быть пустой.
- Перетаскивайте поле для перемещения камеры; колесо мыши меняет масштаб. На телефоне используйте перемещение пальцем и масштабирование двумя пальцами.
- В режиме редактирования нажимайте на клетки, чтобы добавлять или удалять солдат и составлять свои позиции.
- Кнопки отмены и повтора позволяют вернуться к предыдущим ходам. `Ctrl+Z` отменяет действие, `Ctrl+Shift+Z` или `Ctrl+Y` повторяет его.

Цель — поднять солдата как можно выше над границей начальной армии. Редактирование позволяет исследовать собственные позиции.

Проверка игровой логики:

```powershell
npm test
```
